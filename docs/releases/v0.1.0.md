## What This Release Is

SEO Page Creator Agent v0.1.0 is the initial public release of an open-source AI SEO content generator and SEO page creator workflow.

It can start from a website URL and help a host AI coding agent produce research-backed SEO content, structured editorial artifacts, and a locally hosted HTML preview for review before production.

## What Works

- TypeScript CLI with the `seo-agent` command.
- Global npm package: `seo-page-creator-agent`.
- Category discovery from website, business, search, competitor, and audience-language evidence.
- Cluster strategy generation.
- V2 page workflow helpers.
- Content quality gates through Step 11 on-page SEO optimization.
- Structured JSON and Markdown artifacts.
- Editorial QA and validation commands.
- Codex, Gemini CLI, and Antigravity adapter instructions.

## Supported Workflows

- SEO cluster discovery.
- Page opportunity planning.
- SEO content brief creation.
- Research-backed outline and draft workflows.
- On-page SEO optimization.
- Local page packet generation.
- Local HTML-preview-oriented handoff.
- Batch workflow state, locks, and ledgers when configured.

## Installation

```bash
npm install -g seo-page-creator-agent
seo-agent init
```

## Compatibility

- Node.js 22 or later.
- Host AI coding agent recommended for live research and artifact completion.
- Tested adapters: Codex, Gemini CLI, and Antigravity.

## Known Limitations

- Step 12 trust/authority, final metadata, final QA, and publishing readiness are still on the roadmap.
- Live publishing requires a project-specific publishing playbook and repo/CMS/deployment access.
- GitHub repository social preview, repository About fields, topics, and GitHub Release publishing must be configured in GitHub by an authenticated repository owner.

## Upgrade Notes

This is the first public release. No migration is required.
